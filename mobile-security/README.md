# INVYRIX mobile companion

This companion pairs a phone with one institute's exam session. Start it from the repository root with `npm run dev:mobile`; the root `npm run build` produces `dist/mobile/` alongside the main application. Use the root dependency installation and `.env`.

Open the link generated by the desktop exam checks. It includes the institute slug and a session pairing code. Firebase Anonymous Authentication and the deployed `pairMobile` function are required. Database rules restrict that phone identity to its paired session's mobile telemetry. Subscription pause/expiry releases the phone and blocks further exam access.

See the root README for setup, deployment and platform limitations.
